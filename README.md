# 감 테스트 — 공개 데이터로 만든 추측 게임

**당신의 직감과 상식은 얼마나 맞는가?** 화면에 보이는 주제 10개, 주제당 5문항.
**모든 숫자는 공개 데이터에서 직접 계산한 값**입니다. 이대로 Vercel에 올리면 바로 돌아갑니다.

예전 실습 주제 10개(날씨·인구·환율 등)도 코드와 문항 파일은 그대로 있고, 화면 목록에서만
숨겨 두었습니다. 다시 보이게 하는 법은 아래 **「주제 보이기·숨기기」**에 있습니다.

## 돌려보기

```
python -m http.server 8000      # index.html 을 더블클릭하면 안 됩니다
```

## Claude Code 설정

`.claude/settings.json` 은 이 폴더에서 켠 Claude Code가 **수동 모드**(고치기·실행마다 묻는다)로 시작하게 합니다 — 교재 1-4. 배포에서는 빠집니다(`.vercelignore`).

## 올리기

```
1. https://github.com/kym20b/gam-test → Use this template → 내 GitHub 으로
2. vercel.com → Add New → Project → Import
3. Framework Preset: Other → Deploy
```

빌드가 없어서 20~40초면 끝나고, 이후에는 `git push` 할 때마다 자동으로 다시 올라갑니다.

## 데이터가 오는 길

```
   [내 노트북]                                   [인터넷]

   .env                    인증키 (KOSIS · 서울 열린데이터광장)
   tools/fetch_all.py      공개 데이터 받기 (대부분 키·로그인 없음)
        ↓  data/raw/  약 25MB   ← git 에도 배포에도 올라가지 않습니다
   tools/build_topics.py   원본에서 문항 계산
        ↓
   topics/*.json           ← 이것만 올라갑니다
```

원본을 브라우저로 보내서 거기서 평균을 내는 게 아닙니다. **평균은 내 노트북에서 미리
내고, 그 결과만 싣습니다.** 그래서 폰에서 즉시 뜨고, 배포된 사이트에는 키가 필요 없습니다.

```
python tools/fetch_all.py          # 원본 받기 (이미 받은 것은 건너뜀, --force 면 다시)
python tools/build_topics.py       # 문항 계산 → topics/*.json · tools/정답지.md
```

## 인증키 (선택)

통계청 자료와 서울 지하철 자료는 무료 인증키가 있어야 받아집니다. 저장소 최상위에
`.env` 파일을 만들고 아래처럼 적습니다.

```
KOSIS_API_KEY=...      # kosis.kr/openapi → 회원가입 → 활용신청
SEOUL_API_KEY=...      # data.seoul.go.kr → 회원가입 → 인증키 신청
```

- `.env` 는 `.gitignore` 와 `.vercelignore` 에 들어 있어 **GitHub 에도 배포에도 올라가지 않습니다.**
- **키가 없어도 돌아갑니다.** `fetch_all.py` 는 그 파일만 건너뛰고, `build_topics.py` 는 원본이
  없는 주제(또는 문항)만 지난번 계산값(`topics/*.json`)을 그대로 씁니다. 나머지는 다시 계산합니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 한 장 (주제 고르기 · 문항 · 결과) |
| `style.css` | 폰 세로 기준. 색과 간격은 여기서만 정합니다 |
| `app.js` | 진행 · 채점 · 결과 · 공유. **계산은 전부 여기서 끝납니다** |
| `topics.json` | 화면 제목 · 주제 목록 · 등급 · 반응 문구 |
| `topics/*.json` | ★ 주제별 5문항. 정답 · 힌트 · 근거 · 해설 · 한계 |
| `api/comment.py` | Gemini 촌평. 서버가 필요한 유일한 자리 |
| `tools/fetch_all.py` | 공개 데이터 내려받기 (배포 제외) |
| `tools/build_topics.py` | 원본 → 문항 계산 (배포 제외) |
| `.env` | 인증키 (git · 배포 제외) |

## 주제 보이기·숨기기

`tools/build_topics.py` 맨 위의 `SHOWN` 에 들어 있는 주제만 화면 목록에 나옵니다.

```python
SHOWN = {"miss-universe", "money", ...}     # 여기에 "seoul-heat" 같은 id 를 더한다
```

고친 뒤 `python tools/build_topics.py` 를 다시 돌리면 `topics.json` 이 바뀝니다. 숨긴 주제도
계산은 그대로 되고 `topics/*.json` 도 남아 있어, 목록에 넣기만 하면 바로 보입니다.

## Gemini 촌평 (선택)

```
Vercel → Settings → Environment Variables
  GEMINI_API_KEY = (aistudio.google.com 에서 받은 키)
→ 저장하고 다시 배포
```

**키가 없으면 촌평만 빠지고 나머지는 그대로 돕니다.** 로컬(`python -m http.server`)에서는
서버리스 함수가 돌지 않으므로 촌평 자리가 나타나지 않습니다. 정상입니다.

`api/comment.py` 맨 위의 `MODEL` 은 AI Studio 에서 지금 쓸 수 있는 이름으로 맞춥니다.

## 고치는 자리

| 바꾸고 싶은 것 | 어디 |
|---|---|
| 문항 · 정답 · 힌트 · 근거 · 해설 · 한계 | `tools/build_topics.py` → 다시 돌리면 `topics/*.json` 갱신 |
| 화면에 보일 주제 | `tools/build_topics.py` 의 `SHOWN` |
| 화면 제목 · 부제 | `topics.json` 의 `title` · `subtitle` (다시 계산해도 유지됩니다) |
| 등급 이름, 반응 문구 | `tools/build_topics.py` 의 `main()` (`topics.json` 에 씁니다) |
| 점수 계산식 | `app.js` 의 `scoreOne()` |
| 색 · 여백 · 글꼴 | `style.css` 맨 위의 `:root` |

- 슬라이더 문항은 `slider(...)`, 고르기 문항은 `choice(...)` 로 만듭니다. 문항 아래에 작게
  보일 실마리는 `hint="힌트: ..."` 로 넣습니다.
- 슬라이더 눈금(`step`)이 정수면 정답도 정수로 맞춰집니다.

> **숫자를 손으로 옮겨 적지 마십시오.** `build_topics.py` 안에서 계산식으로 넣어야
> 데이터를 다시 받았을 때 자동으로 갱신됩니다.

## 이 데이터를 믿을 때의 한계

각 주제의 결과 화면 맨 아래에 **「이 데이터의 한계」** 상자가 있습니다. 공개 데이터라고
맞는 데이터가 아닙니다. 실제로 이 앱을 만들며 겪은 것들입니다.

- **로또**는 동행복권이 2025년 사이트를 바꾸며 당첨번호 API·엑셀 내려받기를 없애, 새 결과
  화면이 쓰는 **내부 주소**에서 받습니다. 공식 경로가 아니라 사이트가 바뀌면 깨집니다
  (깨지면 로또만 지난번 계산값을 씁니다)
- **짜장면 실제 가격(원)**은 참가격·행정안전부 화면에만 있고 내려받을 원본이 없어,
  물가지수(2020년=100)로 '몇 % 올랐나'만 묻습니다
- **'이혼율'**은 흔히 그해 결혼 100건당 이혼으로 말하지만, 통계청 공식 지표(조이혼율)는
  인구 1천 명당 이혼입니다. 두 숫자는 크기가 전혀 다릅니다
- **지하철** 교통카드 기록에서 환승역은 개찰구를 같이 쓰는 노선 하나에 몰려 잡힙니다
  (충무로 3호선은 거의 0명). 그래서 노선이 아니라 역 이름으로 합쳐 셉니다
- **KOSIS** 는 시작 연도만 주면 그해 값 하나만 돌려줍니다. '최근 N개 연도'로 받아야 새 발표가 따라옵니다
- **ERA5 재분석**의 서울 역대 최고기온은 38.7도(2018년)지만, **기상청 관측 기록은 39.6도**입니다. 날씨는 받는 주소에 `&models=era5` 를 붙여 모델을 고정했습니다 — 적지 않으면 Open-Meteo가 고르는 모델이 바뀌어 지난 값이 달라집니다
- World Bank의 '모든 나라' 목록에는 **유럽연합·고소득국 같은 집계치가 78개** 섞여 있습니다
- 공휴일 API의 2025년 한국 목록에는 제헌절이 공휴일로 들어 있었습니다. **2025년 기준으로는
  틀린 값이지만, 2026년 5월 개정으로 제헌절은 다시 공휴일이 되었습니다** — 같은 값이
  기준 시점에 따라 맞기도 틀리기도 합니다. 공휴일 데이터는 제도 변경에 민감해 주제에서 뺐습니다
